# המרחב שלי — נועה ענבר

אפליקציה בעברית לניהול משימות, יומן, לקוחות, פניות, קשרים, כתיבה ופעילות שבועית. גרסה 0.13.0 כוללת משימות חוזרות ומעקב המשך לפניות.

האפליקציה הפעילה: https://noa-workspace-a4acc.web.app/

## בנייה ובדיקות

נדרש Node.js מודרני (מומלץ 22 ומעלה). אין תלויות npm לבנייה או לבדיקות היחידה.

```sh
npm test
npm run build
```

הבנייה משלבת את קובצי src לתוך dist/index.html. כל 52 בדיקות היחידה עברו בעת שמירת הגרסה במאגר.

## מבנה ופרטיות

src מכילה את הממשק והלוגיקה, tests את בדיקות היחידה ו־scripts את כלי הבנייה ובדיקת התצורה וההרשאות. config.js מכיל תצורת Firebase Web ציבורית ומזהה בעלת החשבון; אין בו סיסמאות, מפתחות שירות או אסימוני גישה. נתוני הלקוחות, המשימות, הפניות והכתיבה נשמרים ב־Firestore ואינם כלולים במאגר. הדוגמאות בקוד הן נתוני התנסות בלבד. הגישה לנתונים מוגבלת באמצעות Firebase Authentication וכללי firestore.rules.

למצב התנסות יש לשנות עותק מקומי של config.js למצב demo ולבנות מחדש; השינויים במצב זה נשמרים בדפדפן בלבד.

## פרסום ב־Firebase

שמירת הקוד ב־GitHub אינה מפרסמת שינויים אוטומטית. בחשבון מורשה עם Firebase CLI:

```sh
npm test
npm run build
node scripts/check-cloud.cjs
firebase deploy --project noa-workspace-a4acc --only hosting
```

פרסום כללי Firestore הוא פעולה נפרדת המחייבת בדיקת הרשאות לפני העלאה. אין לפרסם כללים פתוחים.

חיבור Google Calendar הוא לצפייה בלבד, מתוך היומן באפליקציה; נדרש להתחבר שוב לאחר טעינה או פקיעת ההרשאה. תזכורות הפניות מוצגות בתוך האפליקציה ואינן נשלחות כשהיא סגורה.
